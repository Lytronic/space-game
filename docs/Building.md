# Building the game
This game is developed using the [Godot](https://godotengine.org/) game engine.

## Requirements

- A working Linux, macOS or Windows system
- [Godot 4.6.3 **with .NET support**](https://godotengine.org/download/archive/4.6.3-stable/)
- Microsoft .NET 8.0

Newer versions may be compatible, but are not guaranteed to work.

## Running

After installing the dependencies, running the game should be as simple as opening the project in Godot and hitting the play button on the top right toolbar.

You can also launch the game directly by starting the Godot executable from inside the project directory via the terminal.

If none of this works, you most likely installed the version of Godot *without* .NET support.

Once you're able to open the project, you can also utilise [Godot's export functionality](https://docs.godotengine.org/en/stable/tutorials/export/exporting_projects.html) to generate an independent executable.
